# Web 控制台使用说明

把 AI 操盘手从「脚本」变成「系统」：浏览器里看账户、看 AI 的每一次决策过程、管理选股池、翻复盘与风格演化、改配置与风控。

```powershell
cd astock-watch        # 进入克隆/解压后的目录
python main.py serve                # 打开 http://127.0.0.1:8770
python main.py serve --port 9000    # 换端口
python main.py serve --host 0.0.0.0 # 允许局域网访问（默认仅本机，请勿公网暴露）
```

或双击 `启动Web服务.bat`（会自动打开浏览器）。

> 零依赖：Python 标准库 `http.server` + 原生前端，不需要 npm / 不需要打包。

## 七个页面（含东方财富风格行情图）

### ① 仪表盘
- 总权益 / 累计收益 / 现金 / 持仓数、交易统计（笔数、胜率、盈亏比、回撤）、模型 token 消耗
- 大盘环境（上证/深成/创业板/沪深300）
- **权益曲线**（内联 SVG，无需图表库）
- 当前持仓（成本/现价/浮盈/止损/目标）—— **点任意一行直接跳 K 线**
- **大盘温度卡片**：温度值 / 等级（冰点~过热）/ 指数与涨跌家数 / 涨停跌停 / 上证趋势 / 行业板块强度前 5
- 刷新是**局部更新**（只替换数字与表格，不重建页面），不会闪
- AI 观察池、**待执行计划单**（收盘后决策会存成计划单，次日开盘才成交）、硬风控红线
- 三个一键按钮：**立即决策 / AI 选股 / 收盘复盘**

### ② 行情复盘（分时 / 多周期 / 十字光标 / 点击详情）

对标东方财富的行情页，把「价格走势」和「AI 的行为」放在同一张图上。

**周期切换（9 档）**：分时 ｜ 1分 ｜ 5分 ｜ 15分 ｜ 30分 ｜ 60分 ｜ 日K ｜ 周K ｜ 月K
（K 线周期可再选 60 / 120 / 250 根）

**交互**
| 操作 | 效果 |
|---|---|
| 鼠标移动 | **十字光标**跟随，右上浮层实时显示该点：日期时间 / 开高低收 / **涨跌幅** / 成交量 / 成交额 / 换手率（分时显示时间、价格、均价、涨跌幅、量） |
| **点击某根 K 线（或分时上某一点）** | 锁定该周期，图中高亮 + 下方「选中详情」卡：完整 OHLC、振幅、成交额、MA 值，以及 **AI 在这一刻做了什么**（成交/计划单/决策及理由） |
| 自动刷新（可勾选） | 盘中每 15 秒拉取最新数据，**最后一根 K 线是实时的**（用实时快照合并当日高低收与成交量），分时图实时增长 |
| 标签 | 一键切换持仓 / 观察池 / 计划单里的标的 |

**图元说明**
| 图元 | 含义 |
|---|---|
| 红/绿蜡烛 + 量柱 | 日/周/月/分钟 K 与成交量（A 股红涨绿跌） |
| MA5 / MA10 / MA20 / MA60 | 四色均线（分时图为 价格线 + 均价线 + 昨收基准线，右侧同时显示涨跌幅刻度） |
| **红色 ▲ / 绿色 ▼** | AI 买入 / 卖出成交（悬停看成交时间、股数、价格、理由） |
| **黄色虚线圆 P** | 计划单（信号时间 + 信号价 + 止损，次日开盘执行） |
| **底部彩色小竖线** | AI 每次决策的时点（红=买入意向，绿=卖出意向，蓝=其它） |
| 橙 / 蓝虚线 | 当前持仓的止损线 / 目标线 |

**数据接口**：`/api/kline?code=600015&period=day|week|month|min1|min5|min15|min30|min60|trend&days=120`
返回 K 线/分时序列、均线、AI 成交、计划单、决策时点、持仓，并带 `live` 标记（是否已合并实时价）。

### ③ 我的持仓（真实账户）

记你自己的钱，和 AI 模拟盘完全分开（AI 不会动这里的数据）。

| 功能 | 说明 |
|---|---|
| **资金量** | 填你的本金，用来算仓位占比与可用资金 |
| **录入** | 代码 / 股数 / 成本价 / 买入日期 / 备注，支持多只、随时增删改 |
| **组合概览** | 总市值、持仓成本、浮动盈亏（额与%）、可用资金、仓位占比、风险提示 |
| **逐只分析** | 现价、浮盈、技术评分、右侧确认数、止损与目标位、距止损百分比、**一句话建议**（跌破止损 / 弱势减仓 / 持有观察 / 上移止损保利润） |
| 交互 | 点股票名直接跳 K 线看 AI 买卖点；保存时自动备份（`backups/`） |

分析复用 `signals.build_report`，**不调用大模型、不产生费用**。

### ④ AI 决策（决策过程全透明）
- 左侧：决策流水（时间、kind、市场判断、动作条数、裁决条数）
- 右侧：点开某条 → 模型输出的 `actions`（代码/动作/股数/理由）+ **风控裁决原文**（通过还是被拒、为什么）
- 下方三块审计入口：
  - **发给模型的提示词**（当时的完整数据快照）
  - **完整报告文件**（模型原始输出 + 风控结果 + 输入快照 + token 用量）
  - **解析失败诊断**（`data/ai/failed/`：原始输出 + `finish_reason`，用来判断是不是被截断）

这一页就是回答「AI 当时到底看到了什么、想了什么、为什么这么干」。

### ④ 选股池
- **AI 观察池**：可直接编辑 6 位代码，显示 AI 挑选理由
- **规则初筛候选池**：一键「重新扫描全市场」，列出 ~20 只有形态标签的候选
  （突破新高 / 回踩均线 / 超跌反弹 / 放量异动 / 多头排列，含距 MA20、60 日分位、RSI、量能、候选分）
- 每行「+池」可把候选加入观察池（AI 之后就在这个池子里挑）

### ⑤ 复盘
- 绩效三卡（收益 / 胜率与盈亏比 / 回撤与手续费）+ 权益曲线
- **AI 交易日记**（按日，点开看全文）
- **AI 积累的教训库**（它自己写的、下次开盘要执行的规则）
- 成交明细（时间/方向/价格/股数/盈亏/理由）

### ⑥ 风格手册
- **当前手册**：AI 自己维护的交易哲学、开仓条件、卖出条件、仓位纪律
- **版本历史**：每次收盘复盘都会重写并归档旧版 → 直接看它的风格怎么一步步变的

### ⑦ 设置
- AI 大脑：provider（openai/custom/deepseek/ollama）、base_url、model、api_key、temperature、
  各阶段输出额度（max_tokens_pick / decide / review / playbook —— 思考型模型额度不足会被截断，导致解析失败）
- **硬风控 10+ 项**（单股/总仓/笔数/单笔风险/**组合风险**/熔断/价格区间/委托价偏离/追高禁买/恐慌禁卖）
- 自动调度开关与时间（盘中每 N 分钟决策、选股时间、复盘时间、开盘执行计划单）
- 手动操作：全市场扫描 / AI 选股 / AI 决策 / 收盘复盘 / 执行计划单 / 重置模拟盘
- **数据备份**：立即备份、备份列表、点条目回滚（含账户/成交/手册/日记/教训/计划单）
- **扩展数据源**：显示 akshare / tushare 是否安装

## 服务端结构

```
astock/server.py
├── HTTP 服务      ThreadingHTTPServer + 路由表（GET_ROUTES / POST_ROUTES）
├── 任务队列       异步并发（默认上限 4 个）：线程级 stdout 路由 → 每个任务的日志互不串台
│                  账户类任务（决策/执行）加互斥锁串行，避免持仓与现金写冲突
│                  其它任务（选股/扫描/复盘）可同时跑
├── 调度器         Scheduler 线程：每分钟记权益；盘中按间隔决策；到了 pick_at/review_at 自动跑
└── 安全           只监听 127.0.0.1、文件读取限制在固定目录（防目录穿越）、
                  api_key 只回显掩码（****后4位）且掩码不会覆盖真 key
```

### API 一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/overview` | 账户/持仓/统计/大盘/风控/调度/用量 |
| GET | `/api/equity` | 权益曲线 |
| GET | `/api/decisions?days=5` | 决策流水 |
| GET | `/api/reports`、`/api/decision?f=` | 报告列表 / 报告全文 |
| GET | `/api/prompts`、`/api/prompt?f=` | 提示词列表 / 全文（审计） |
| GET | `/api/candidates` | 候选池（含形态标签与评分） |
| GET/POST | `/api/watchlist` | 读取/设置观察池 |
| GET | `/api/journal`、`/api/journal?d=` | 日记列表 / 全文 |
| GET | `/api/lessons` | 教训库 |
| GET | `/api/failed`、`/api/failed?f=` | 解析失败诊断列表 / 原文 |
| GET | `/api/kline?code=&days=` | K线 + MA + AI 成交点 + 计划单 + 决策时点 + 持仓 |
| GET | `/api/playbook`、`/api/playbook/file?f=` | 当前手册 / 历史版本 |
| GET | `/api/trades` | 成交明细 + 统计 |
| GET/POST | `/api/config` | 读取/保存配置（key 掩码保护） |

| GET | `/api/job?id=`、`/api/jobs` | 任务状态与实时日志（含并发数、是否排队、耗时） |
| POST | `/api/reset` | 重置模拟盘（保留手册/日记/教训） |

## 典型一天

```
09:20  打开 http://127.0.0.1:8770 → 仪表盘看昨日权益与持仓
09:30  调度器开始每 30 分钟自动决策（可手动「立即决策」）
       AI 决策记录实时出现在「AI 决策」页，被风控拒绝的指令也能看到原因
14:5x  盯「AI 决策」页最后一条，决定是否跟随（你随时可以手动干预）
15:05  自动复盘：AI 写自评、教训，重写风格手册
15:12  自动选股：生成明日观察池
盘后    到「复盘」页看日记与教训，到「风格手册」页看它这周的想法有没有变
```

## 注意事项

1. **默认只监听 127.0.0.1**。若用 `--host 0.0.0.0` 让手机/其它机器访问，请自行加反向代理与鉴权（本服务没有登录验证）。
2. **api_key 保存在本机 `config.json`**，前端只显示后 4 位；用掩码保存不会覆盖真实 key。
3. **重置模拟盘不会清空 AI 的记忆**（手册/日记/教训保留），只清资金与持仓。
4. 服务重启后，内存中的任务列表会清空，但磁盘上的决策/报告/日记都在。
5. 仍然**不接券商、不下真单**。
