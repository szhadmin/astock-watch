# AI 自主操盘手（A 股 · 模拟盘）

> 让大模型自己读 K 线、自己选股、自己决定买卖、自己复盘改进，用来回答一个问题——
> **「AI 在 A 股到底能不能赚钱？」**
> 本工具**只做实盘分析 + 模拟盘成交**，不接券商、不下真单。

---

## 一、30 秒开始

```powershell
cd astock-watch        # 进入克隆/解压后的目录

# 1) 配好大脑：Web「设置」页填 provider / base_url / model / api_key
python main.py serve            # 打开 http://127.0.0.1:8770 → 设置

# 2) 体检：网关 / JSON / 围栏 / 截断 / 双调用 / 风控，一步到位
python main.py ai --doctor

# 3) 跑三个角色
python main.py ai --phase pick    # ① 选股会
python main.py ai --phase decide  # ② 操盘决策（收盘后 = 生成次日计划单）
python main.py ai --phase review  # ③ 收盘复盘（写教训 + 重写手册）

python main.py ai --status        # 账户与绩效
python main.py ai --phase execute # 开盘后执行昨日计划单
```

## 二、它到底"智能"在哪

```
① 选股会（收盘后）  5000只 →规则初筛300 →逐只读90根日线→20只形态档案
                    AI 按自己的手册挑 3~5 只（写理由，也会主动排除）

② 操盘（盘中/收盘后）
    盘中   → AI 决策后立刻按现价成交（先过风控）
    收盘后 → 只生成「次日计划单」，次日开盘才执行
             开盘高开 >1.5% 或跳空跌破止损 → 自动取消（不追高、不接刀）

③ 复盘进化（收盘）  两次调用：先 JSON 结论（critique/lessons），再单独写 Markdown 手册
                    旧手册归档 → 第二天按新版手册行动 → 风格一点点变化
```

**「养成自己的风格」= 持久记忆 + 每日自审 + 手册重写。**
真实跑过一次后，AI 自己写下的教训（原文摘录）：

> 教训1：收盘后只生成次日计划单，次日 9:30–10:00 执行；开盘价高于信号日收盘价 1.5% 则取消，禁止再用收盘价成交。
> 教训2：开盘先算组合总止损风险 = Σ(入场价−止损价)×股数 / 总权益；若 >2.0%，优先减掉风险金额较大的持仓。
> 教训3：同日开第二笔前重算组合风险；若两笔合计 >2.0%，第二笔不下单。

它指出的「收盘后用收盘价成交 = 事后偷价」是**真实的系统缺陷**，已据此改造下单机制（计划单 + 隔夜跳空取消 + 组合风险上限）——这就是让 AI 参与系统设计的意义。

## 四、硬风控：AI 不许越界的红线

写在 `config.json → ai.rails`（Web「设置」可改，**AI 自己改不了**）：

| 约束 | 默认 | 说明 |
|---|---|---|
| 单股仓位上限 | 40% | 超了自动裁剪 |
| 总仓位上限 | 80% | 始终留 20% 现金 |
| 每日最多交易 | 4 笔 | 防手痒刷佣金 |
| 单笔最大风险 | 1.5% 本金 | 按 (买价−止损)×股数 算 |
| **组合风险上限** | **2.0% 本金** | 全部持仓「到止损的距离」之和（AI 自己提的规则，已代码化） |
| 当日亏损熔断 | 3% | 触发后当日禁止开新仓 |
| **大盘温度闸门** | 动态 | 温度<30 禁止开新仓；30~44 单股上限压到 25%（代码执行，模型无法绕过） |
| 价格区间 | 2~40 元 | 1.5 万本金买得起买得动 |
| 追高禁令 | 涨幅 ≥8% 不买 | 不接涨停 |
| 恐慌禁令 | 跌幅 ≥8% 不卖 | 不割在地板，次日处理 |
| 委托价偏离 | ≤2.5% | 防 AI 乱报价 |
| 最小开仓 | 200 股 | 太小手续费不经济 |
| 标的白名单 | 持仓 ∪ 观察池 ∪ 候选池 | 杜绝编造代码 |
| T+1 / 整手 / 费率 | — | 与真实 A 股一致 |

```powershell

python selftest_plans.py  # 计划单执行 4 个场景（高开取消 / 跳空跌破止损取消）

## 五、下单机制：为什么有"计划单"

真实交易里最隐蔽的自欺是**事后偷价**：收盘后拿收盘价成交，模拟/回测都会虚高。

- **交易时段内**（9:30–11:30 / 13:00–15:00）：AI 决策 → 风控 → 立即成交，成交价夹在当日高低之间；
- **非交易时段**：AI 决策 → 存成 `data/ai/plans/pending_plans.json` → **次日开盘执行**：
  - 开盘价比信号价高 >1.5% → 取消（不追高）
  - 开盘已跌破止损 → 取消（不接刀）
  - 执行前重跑一遍风控（价格变了，仓位/风险重新算）

## 六、故障排查（真网关常见的四类坑）

| 症状 | 原因 | 解决 |
|---|---|---|
| `复盘输出解析失败` | 输出被截断（思考型模型的 `completion_thinking_tokens` 吃掉额度） | 调大「设置 → max_tokens_review / max_tokens_playbook」；系统已内置 `finish_reason=length` 检测并自动加倍重试 |
| `模型只输出了思考内容、没有正文` | 额度全被 reasoning 吃掉，正文为空 | 把该阶段 max_tokens 调到 4000~8000（决策 5000、复盘 4000、手册 5000 是实测可用的值） |
| JSON 解析失败但内容看着对 | 模型把 JSON 包在 ` ```json ` 围栏里 | 已自动剥离；仍失败时用 JSON 修复器补齐被截断的括号 |
| `模型调用失败：400 ...` | 网关不支持 `response_format` | 已自动去掉该参数重试一次 |
| `401/403` | key 错或无权限 | Web「设置」重填 key（只显示后 4 位，掩码保存不覆盖真 key） |

失败原文全部留档在 `data/ai/failed/`，Web「AI 决策」页点开可看 `finish_reason` 与提示词。

**一键体检**：`python main.py ai --doctor` —— 依次检查网关连通、JSON、代码围栏、长输出额度、复盘双调用、风控配置。

## 七、可审计性

```
data/ai/
├── prompts/     每次发给模型的完整提示词（含当时全部数据）
├── reports/     模型原始输出 + 风控裁决 + 输入快照

```

## 九、必须知道的四个真相

1. **大概率不赚钱。** LLM 在「读懂结构化数据 + 守纪律」上很强，在「预测短期价格」上没有稳定优势。这个工具的用途是**用极低成本得到一个可审计的答案**。
2. **回测好看 ≠ 实盘能赚。** 规则策略在 000620 上 239 天 +10.45%（买入持有 −22.19%），但只是一只票一年样本，且参数事后调过。
3. **AI 会"自欺式作弊"**（例如用收盘价成交），所以风控必须写在代码里，不能只写在提示词里。
4. **先跑 30~60 天模拟盘**，只盯三个数：① 胜率×盈亏比 是否 > 交易成本（约 0.2%/次）② 最大回撤你是否受得了 ③ 手册是不是在**变具体**。
